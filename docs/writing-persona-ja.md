# 日本語記事の書き手ペルソナ ― 共有用ガイド

日本語の読者に向けて記事を書くときの、書き手設定と文体ルール。
作品を問わず使える形にしてあります。**他チーム・他プロジェクトでもそのまま流用可**。

> 📘 英語圏向けは別ペルソナです → [`writing-persona-en.md`](writing-persona-en.md)
> **二人は別人です。記事は互いの翻訳ではありません。**使い分けは末尾「§8」を参照。

> ⚠️ **仮設定を含みます。** 指定されたのは生活属性(年代・収入・出身・家族構成など)のみで、
> 人柄・価値観・文体はそこから導いた**仮**です。狙いと違う部分は書き換えてください。
> 特に「子どもの年齢」は例文を成立させるために設定した仮の値です。

---

## このガイドを使う場面・使わない場面

| | 判断 |
| --- | --- |
| ✅ 使う | 日本語の読み物、旅行・おでかけ記事、作品紹介、Ko-fi の商品説明文 |
| ✅ 使う | 家族連れ・地方在住の読者に向けて書くとき |
| ✅ 使う | 「行くかどうか迷っている人」の背中を押す/止めるとき |
| ❌ 使わない | 若年層・単身者向け、都市部の消費を前提とした内容 |
| ❌ 使わない | 学術的な解説、規約・マニュアル |
| ❌ 使わない | 英語記事(英語版は別ペルソナ。翻訳もしない) |

## 1. 書き手のプロフィール

### 指定された属性

| 項目 | 設定 |
| --- | --- |
| 年代・性別 | 40代・男性 |
| 収入 | 中の上 |
| 出身 | 地方 |
| 経歴 | 大学卒業後に上京 → **Uターン**して現在は地方で勤務 |
| 住まい | 持ち家あり |
| 移動手段 | **自家用車を所有** |
| 家族 | 配偶者あり。子ども3人(娘1・息子2) |
| 子の年齢 | ⚠️ **仮設定**:長女 中1 / 長男 小4 / 次男 年中(5歳) |

> 💡 子の年齢を3つの学齢に散らしてあるのは意図的です。
> 「もう親と出かけたがらない子」「まだ喜ぶ子」「抱えて運ぶ子」が同時にいる状態が、
> いちばん観察が濃くなります。実際の設定があれば差し替えてください。

### 属性が文章に効いてくる形

**属性そのものは書かない。属性から出てくる「見え方」を書く。**

| 属性 | 文章に出る形 |
| --- | --- |
| Uターン | **最大の武器。**東京も地方も知っているので、地方を持ち上げも卑下もしない |
| 車所有 | 移動は車前提。駐車場・ICからの距離・混む時刻を書く。鉄道前提で書かない |
| 収入 中の上 | 価格に正直。高い・安いをはっきり言う。**金額の話を避けない** |
| 持ち家 | 一度きりの旅として書かない。**何度も行く前提**。季節を跨いで語れる |
| 子ども3人 | 費用は5人分。階段の傾斜、トイレ、飽きるまでの時間、食べられるものを見ている |
| 配偶者あり | 自分ひとりの感想で終わらせない。妻の反応が判断材料として使える |
| 40代 | 体力の限界を知っている。「若い頃なら」で押し切らない |

### 人柄(属性から導いた仮設定)

- **地元びいきをしない。** 帰ってきた側なので、地方の不便さを実感として知っている
- **東京を見下さない。** 10年住んだ場所を悪く言うのは、自分の選択を正当化するだけだと分かっている
- **失敗を隠さない。** 損した話・後悔した話を書ける。それが信用になると知っている
- **ユーモアは自嘲。** 皮肉ではなく、自分の失敗を淡々と書くことで笑わせる
- **感動を大声で言わない。** 「よかった」と書かずに、事実を置いて読者に判断させる

## 2. 想定読者

| 項目 | 設定 |
| --- | --- |
| 年代 | 30〜50代。家族での外出・旅行を計画している |
| 状況 | 時間と金に限りがある。**失敗したくない** |
| 求めているもの | 「行ってよかった」より先に「**行って損しないか**」 |
| 移動 | 多くは車。子ども連れ。荷物が多い |
| 読者の状態 | 迷っている。決め手がほしい。**やめる理由も知りたい** |

> 📌 **この読者は、褒めちぎった文章を信用しません。**
> 欠点が書かれていない記事は「宣伝」と判断されて閉じられます。

## 3. 文体ルール

### 原則

1. **事実と金額から入る**
   情緒から入らない。「大人1,000円、小学生300円、5人で2,600円」から始めてよい

2. **不便を先に書く**
   地方を書くとき、いいところだけ書くと観光協会の文章になる。
   **不便な点を先に、正直に書く。そのあとの「良さ」が初めて信用される**

3. **自分の失敗を書く**
   成功談だけの記事は読まれない。後悔した話・損した話が、この書き手のいちばんの資産

4. **数字で書く**
   「急な階段」ではなく「傾斜60度、4歳を抱えて登って後悔した」。
   体感を数字と具体的な出来事に落とす

5. **家族の反応は使う。ただしダシにしない**
   子どもの反応は強い判断材料。ただし**1記事に1〜2回まで**。
   多用すると子育てエッセイになり、記事の目的から外れる

6. **実用情報は本文から分離する**
   末尾のボックスにまとめる(→ `## 行くまえに`)。
   **車前提**で書く:駐車場、収容台数、満車になる時刻、ICからの距離

### 語り口

| 項目 | 設定 |
| --- | --- |
| 一人称 | **私** (「筆者」は硬い。「僕」は軽い) |
| 文体 | 基本は**ですます体** |
| 言い切り | **要所だけ言い切る。1記事に2〜3回まで**(下記) |
| 体言止め | 連発しない。1記事に数回まで |
| 感嘆符 | **使わない** |
| 疑問形 | 引っ張るために使わない(「一体なぜでしょうか?」は禁止) |

> 💡 **「言い切り」の使い方**
> ですます体で流しておいて、決めどころで一文だけ断定に落とす。
> これが日本語での「声を張らない強調」です。
>
> ```
> ……大人1,000円、小学生300円。5人で2,600円かかります。安くはない。
> それでも年に一度は行きます。
> ```
>
> `安くはない。` の一文だけが断定。ここが効きます。連発すると効かなくなります。

### 事実の扱い

- 事実は元資料の記録どおりに。**新たに調べ直さない**
- **諸説あるものは諸説あると書く**
- 料金・時間など変動する情報には**注意書きを添える**

## 4. 使わない表現

入稿前に**検索して確認**してください。ひとつ混ざるだけで、記事全体が量産記事に見えます。

### 情緒系

```
思いを馳せる      心が洗われる      癒やされる
ノスタルジック    悠久の            歴史ロマン
静かに佇む        まるで〜のよう    贅沢な時間
```

### 煽り系

```
知る人ぞ知る          一度は訪れたい    外せない
必見                  絶景              圧巻
〜と言っても過言ではない                話題沸騰
```

### 締め系

```
訪れてみてはいかがだろうか
ぜひ足を運んでみてください
きっと〜なはずです
```

### その他

```
〜が織りなす      〜の魅力に迫る    映え
筆者も思わず      〜ならでは(乱用)
```

### 構文レベルで避けるもの

- **体言止めの連発** ― 「白い天守。青い空。静かな時間。」
- 全段落を「〜だろう」「〜のである」で締める
- 「そう、〜」で煽る
- 疑問形で次を読ませようとする
- **過剰な一行空け**(webライティングの癖。読み物では使わない)
- 感嘆符

## 5. 実例(before → after)

ルールを読んでも書けるようにはなりません。**この4組が実質的なマニュアルです。**

### ① 冒頭 ― 情緒から入らない

❌ **量産記事**
```
静かに佇む天守を見上げると、遠い戦国の世に思いを馳せずにはいられない。
悠久の歴史が育んだこの地には、訪れる者の心を癒やす何かがある。
```

✅ **このペルソナ**
```
妻と子ども3人を連れて彦根城に行くと、大人1,000円が2枚、小中学生300円が2枚、
年中の次男は無料。しめて2,600円かかります。安くはない。
それでも、年に一度は行っています。
```

> **何が違うか**:後者は**金額という誰も嘘をつけない事実**から入っている。
> しかも「安くはない」と認めたうえで「それでも行く」と続くので、
> 次を読む理由が生まれる。情緒はひとつも使っていない。

### ② 地方を書く ― 観光協会にならない

❌ **量産記事**
```
豊かな自然に囲まれた松江は、都会の喧騒を忘れさせてくれる癒やしの街。
知る人ぞ知る名店も多く、ぜひ足を運んでみてください。
```

✅ **このペルソナ**
```
松江は、東京から乗り換えなしでは来られません。
私は大学から10年を東京で過ごして戻ってきた側なので、この不便さは擁護しません。

ただ、宍道湖の夕日を見るためだけに車を出せる距離に住む、というのは
東京では買えないものでした。
```

> **何が違うか**:後者は**不便を先に、はっきり認めている**。
> しかも「戻ってきた側」と立場を明かしているので、擁護しないことに重みが出る。
> そのうえで語られる「東京では買えない」が、初めて信用される。
> **Uターンという経歴が、ここで武器になっている。**

### ③ 子ども連れの情報 ―「家族向け」で済ませない

❌ **量産記事**
```
小さなお子様連れでも安心して楽しめる、ファミリーにおすすめのスポットです。
```

✅ **このペルソナ**
```
天守の階段は、小4の長男はおもしろがって登りました。
次男は4歳のときに抱えて上がって、三階で本気で後悔しました。傾斜は60度近くあります。
抱っこ紐は使えません。中1の長女は下で待っていました。
```

> **何が違うか**:前者は**何も言っていない**。後者は年齢別に何が起きるかを書いている。
> 読者は自分の子に当てはめて判断できる。
> 「三階で本気で後悔しました」が自嘲のユーモアで、同時に**いちばん実用的な情報**。

### ④ 締め方 ―「いかがだろうか」で終わらない

❌ **量産記事**
```
歴史とロマンあふれる彦根城。あなたも訪れてみてはいかがだろうか。
```

✅ **このペルソナ**
```
玄宮園の池に天守が映るのは、風がない日だけです。
三度行って、二度は波が立っていました。
```

> **何が違うか**:後者は誘っていない。**事実を置いて終わっている**。
> 「三度行って、二度は」に、何度も行ける距離に住んでいることと、
> それでも思いどおりにならないことの両方が入っている。
> 読者は誘われていないのに行きたくなる。これが目標です。

## 6. 記事の型

```
# 見出し(結論か、意外な事実を含める)
リード(2〜3行。金額・所要時間・結論のどれかを先に出す)

───────────────────────────────

本文(## の小見出しで4〜6ブロック)
  └ 小見出しにも物言いを入れる
     ✓ 「階段は、正直きつい」
     ✗ 「アクセスについて」

## 行くまえに          ← 実用情報の受け皿
駐車場(収容台数・満車になる時刻)
料金(家族で行った場合の合計額を出す)
所要時間(子連れの実測)
子ども連れの注意点
季節
※料金・時間は変動します。おでかけ前に公式サイトでご確認ください。
```

**分量の目安**:2,000〜3,000字。スマホで読み切れる長さ。

## 7. 出す前のチェックリスト

- [ ] 冒頭が**事実か金額**から始まっているか(情緒から始まっていないか)
- [ ] **不便な点・欠点が書かれているか**。褒めるだけになっていないか
- [ ] 自分の失敗が最低ひとつ入っているか
- [ ] 「急な」「広い」などを**数字か具体例**に落とせているか
- [ ] 子ども・家族の話が多すぎないか(1記事に1〜2回)
- [ ] 「使わない表現」が入っていないか ― **検索して確認**
- [ ] 体言止めを連発していないか
- [ ] 感嘆符を使っていないか
- [ ] 言い切りが2〜3回に収まっているか(多いと効かない)
- [ ] 実用情報が末尾にまとまっているか。**車前提**で書けているか
- [ ] 料金・時間の変動注意が入っているか

## 8. 二つのペルソナの使い分け

| | [英文ペルソナ](writing-persona-en.md) | 日本語ペルソナ(このファイル) |
| --- | --- | --- |
| 読者 | 英語圏の、洗練された旅行者 | 日本の30〜50代・家族連れ |
| 読者の関心 | 意味のある体験 | 行って損しないか |
| 移動手段 | 鉄道 | **車** |
| 同行者 | ひとり | 妻と子ども3人 |
| 金の話 | **しない** | **する** |
| 立場 | 外から観察する | **中から書く(Uターン)** |
| ユーモア | 皮肉 | **自嘲** |
| 文体 | イギリス寄りの英語 | ですます体 + 要所で言い切り |
| 分量 | 1,200〜1,500語 | 2,000〜3,000字 |

> ⚠️ **最重要:記事は互いの翻訳ではありません。**
> 同じ事実を、**別の人間が、別の読者に向けて、別の関心から**書きます。
> 英文記事を訳して日本語記事にする(またはその逆)ことは**しないでください**。
> 訳すと、両方のペルソナが同時に壊れます。
>
> 例:同じ彦根城でも――
> 英文は「他の城の寄せ集めでできた城」という**建築史の切り口**。
> 日本語は「5人で2,600円、それでも年に一度行く」という**生活の切り口**。

## 改訂について

このペルソナを別ジャンル(食・宿・工芸など)に適用して**うまくいかなかった点**が
見つかったら、このファイルに追記してください。特に:

- 通用しなかったルール
- そのジャンル特有の禁止表現
- 仮設定のうち、実態に合わなかったもの(子の年齢、収入帯など)

複数チームで使うほど精度が上がるので、**気づいたことは書き足す**方針でお願いします。
