# Ko-fi セットアップ手順(アカウント作成後)

アカウントを作った後、どこから設定すればいいか迷わないための手順書です。
**「お金を受け取れる状態にする → 見た目を整える → 商品を並べる」** の順に進めます。
上から順にチェックを付けていけば、迷わず公開まで到達できます。

> 設定画面はすべて Ko-fi 右上のアイコン → `Settings`(設定)から入れます。

---

## 🔴 STEP 1. まず最優先:お金を受け取れるようにする

これが終わらないと、売上や支援を受け取れません。最初に必ず。

- [ ] **決済を連携する**(`Settings → Payments`)
  - **日本で日本円(JPY)を扱うなら Stripe を推奨**(手数料・使い勝手で無難)
  - Stripe アカウントが無ければ、連携の流れでその場で作成できる
  - PayPal でも受け取り自体は可能(併用も可)
- [ ] **通貨(Currency)を JPY に設定する**
  - ⚠️ 後から変えると価格設定がやり直しになりやすいので、**商品を作る前に**決める
- [ ] **本人確認 / 銀行口座の登録**(Stripe 側で求められる場合)
  - 入金先の口座を登録しておく

---

## 🟡 STEP 2. 次に:ページの見た目を整える(お客さんに見える部分)

- [ ] **ページURLを確定する**(`ko-fi.com/〇〇`)
  - ⚠️ 後から変えると宣伝リンクが無効になるので、**早めに確定**
- [ ] **表示名(Display Name)** を設定(チーム名・作家名など)
- [ ] **アイコン画像**をアップロード
- [ ] **カバー画像**をアップロード(作品/チームの雰囲気が伝わるもの)
- [ ] **自己紹介文(Bio / About)** を記入
  - 何を作っているチームか、何が買えるかを一言で
- [ ] **支援ボタンの単価・表記**を設定(「Support me」など)

---

> ✅ **STEP 1・2 は完了済み**(2026-07)。ページは **https://ko-fi.com/zenkyu** で公開中。

## 🟢 STEP 3. 作品を売る:Shop を有効化して商品を登録

> 📌 **商品登録の具体的な手順と、貼り付ける文面は
> [`kofi-shop-登録手順.md`](kofi-shop-登録手順.md) にまとめてあります。**

製作チームの本命。デジタル作品はここで販売します。

- [ ] **Shop を有効化する**(`Settings` または `Shop`)
- [ ] **商品を追加する**(1作品ずつ)
  - ファイルをアップロードすると、購入後に**自動でダウンロード配信**される
  - 各項目は [`../templates/kofi-listing.md`](../templates/kofi-listing.md) を埋めれば説明文が完成
  - [ ] タイトル
  - [ ] 説明文・内容物
  - [ ] 価格(JPY)
  - [ ] サムネイル画像
  - [ ] 配信ファイル(PDF / PNG / ZIP など)
- [ ] **出品前チェック**:誤字脱字 / 価格 / 内容物の過不足 / サムネイル

---

## ⚪ STEP 4. 慣れてから(後回しでOK)

必要になったら手を付ければ十分な項目です。

- [ ] **Membership(月額サポート)** — 継続支援を募りたくなったら
- [ ] **Commissions(受注制作)** — オーダーメイドを受けるなら
- [ ] **Goal(目標金額バー)** — 目標を見せてモチベを共有
- [ ] **SNS / Discord 連携** — 集客・コミュニティ運用
- [ ] **税・請求まわりの確認** — 売上が増えてきたら

---

## まず今日やること(最短ルート)

1. **STEP 1 の決済連携 + 通貨JPY**
2. **STEP 2 のページURL確定**

この2つだけ済ませれば「受け取れる箱」は完成。あとの見た目・商品はいつでも足せます。
