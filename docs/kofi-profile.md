# Ko-fi プロフィール

Ko-fi ページに設定する文面一式。**そのままコピーして貼れる形**にしてあります。
画像(カバー・アイコン)は `works/日本の国宝ガイド/output/` に生成済み。

> 設定場所:Ko-fi 右上アイコン → **Settings → Page / Profile**

---

## 1. 表示名(Display Name)

**日本の国宝ガイド**

> 英語圏の読者も想定するなら併記形も可:
> `日本の国宝ガイド / Japan's National Treasures`

**考え方**:個人名より**作っているものの名前**を出すほうが、
はじめて来た人に「何を配っている人か」が一瞬で伝わります。

## 2. ページURL

`ko-fi.com/nationaltreasures` などの候補。

- ⚠️ **URLは後から変えると宣伝リンクがすべて無効になります。** 最初に確定させること
- 短く・打ちやすく・作品内容がわかるものを
- 候補:`nationaltreasures` / `kokuhoguide` / `japancastles`

> すでに設定済みなら、**そのまま変えないのが正解**です。

ページ本文に置く、もう少し詳しい紹介です。

### 日本語

```
日本の「国宝」を一つずつ訪ね、写真・歴史・建築の見どころ・行き方まで
まとめたデジタルガイドを作っています。

いま進めているのは「国宝五城」シリーズ。

姫路城・松本城・犬山城・彦根城・松江城。

「読んでから行く」「行ってから読み返す」——
どちらにも応える一冊を目指しています。

掲載写真はパブリックドメイン、CC0、またはCC BYライセンスのものを使用し、
```

### 英語

```
I make illustrated digital guides to Japan's National Treasures —
one site at a time, with photographs, history, architecture and
practical directions for getting there.

The series in progress is the Five National Treasure Castles.

Himeji, Matsumoto, Inuyama, Hikone and Matsue.

· History, from founding to the present day
· How to actually read the architecture

Written to work either way round — read it before you go,

All photographs are used under public domain, CC0 or CC BY licences,
with sources and licences credited in each volume.
```

## 5. サポートボタンの表記

Ko-fi の「コーヒー1杯」表記は変更できます。作品の世界観に寄せると印象が変わります。

| 案 | ボタン表記 |
| --- | --- |
| 素直 | Support（サポート） |
| 世界観 | 拝観料をおさめる / Leave a tip at the gate |
| 軽い | お茶を一杯 / Buy me a tea |

> ⚠️ 凝りすぎると「何のボタンか」が伝わらなくなります。
> **迷ったら Support のままが無難**です。

## 6. タグ・カテゴリ

### ページのカテゴリ

Ko-fi の「What do you create?」で選ぶ区分。作品の性質からは:

- **Writing / Publishing**(文章・出版物)が第一候補
- 写真を前面に出すなら **Photography** も可
- 迷ったら Writing。PDFの読み物が主商品のため

### 商品タグ(Shop アイテムに設定)

英語圏からの流入も見込めるため、**日英を混ぜて設定**します。
Ko-fi の検索と外部検索の両方に効きます。

**姫路城(日本語版)**
```
姫路城, 国宝, 日本の城, 城めぐり, 世界遺産, 日本史, 旅行ガイド, 建築, 兵庫, PDF
```

**姫路城(英語版)**
```
himeji castle, japanese castle, national treasure, unesco world heritage,
japan travel guide, japanese history, architecture, kansai, samurai, pdf guide
```

**五城セット(今後)**
```
国宝五城, 日本の城, 城めぐり, 姫路城, 松本城, 犬山城, 彦根城, 松江城,
japanese castles, japan travel, castle guide, bundle
```

### タグを選ぶ考え方

| 種類 | 例 | 役割 |
| --- | --- | --- |
| **固有名詞** | 姫路城 / himeji castle | 目的買いの人に当てる。最優先 |
| **カテゴリ** | 日本の城 / japanese castle | 「城が好き」な層に広く当てる |
| **文脈** | 旅行ガイド / japan travel guide | 旅行を計画中の人に当てる |
| **形式** | PDF / pdf guide | 何が届くかを明示。誤解を防ぐ |

> 💡 **固有名詞タグがいちばん強い**です。「姫路城」で探している人は、
> すでに買う気があります。城名は必ず入れてください。
>
> ⚠️ 関係の薄いタグを大量につけるのは逆効果です。10個前後に絞ります。

## 7. 画像

| 用途 | ファイル | サイズ |
| --- | --- | --- |
| カバー(ヘッダー) | `works/日本の国宝ガイド/output/kofi_cover.png` | 1600×500 |
| アイコン(アバター) | `works/日本の国宝ガイド/output/kofi_avatar.png` | 800×800 |

> ⚠️ **カバーは表示環境によって上下・左右が切られます。**
> 生成した画像は文字を中央寄りに置き、周囲に余白を取ってあるため、
> 多少トリミングされても文字が欠けません。
>
> ⚠️ アイコンは円形に切り抜かれて表示される場合があります。
> 四隅に重要な要素を置かない設計にしてあります。

作り直すには:

```bash
bash works/日本の国宝ガイド/layout/build_profile.sh
```
