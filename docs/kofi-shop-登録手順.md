## その他の設定項目

| 項目 | 設定 | 理由 |
| --- | --- | --- |
| **Categories** | 読み物・書籍に相当するもの(Writing / Books など)を選ぶ。Travel・Education があれば併せて | Ko-fi 内の検索・回遊で見つけてもらう導線。写真集ではなく読み物なので Photography より Writing 系 |

| **Who can buy this item** | **Everyone** | Monthly supporters にするとメンバー限定になり、誰も買えなくなる |

## 登録後の確認

- [ ] **Product summary(短い要約)** を入れた ← 見落としやすい
- [ ] **購入者向けメッセージ**を入れた
- [ ] **Who can buy this item = Everyone** になっている
- [ ] 通貨が **JPY** になっている
- [ ] 配信ファイル(PDF)が正しく添付されている
- [ ] サムネイルが表示されている
- [ ] **自分で購入テスト**をして、ダウンロードが届くか確認した
- [ ] 商品ページのプレビューで説明文の改行が崩れていない

### テスト購入のやり方

**自分のアカウントからは自分の商品を買えないことが多い**ため、次の手順で行います。

1. ブラウザの**シークレット(プライベート)ウィンドウ**を開く
2. `https://ko-fi.com/zenkyu` を開く(未ログイン状態になる)
3. Shop から商品を選んで購入する
4. **普段と違うメールアドレス**を入力(Gmail なら `〜+test@gmail.com` が使える)
5. 決済する

**費用**:¥500 を払い、手数料を引いた額が自分に戻る。実質負担は数十円程度。
ダウンロードが届かない商品を売ってしまうリスクを考えれば安い。

> 💡 Shop の設定に**割引コード**の機能があれば、100%オフのコードを自分で使う方法もあります。
> 価格を一時的に **¥0** にして無料DLでテストし、確認後に戻す手も(Ko-fi が ¥0 商品を許可していれば)。

**確認する5点**

1. ダウンロードリンクが届くか(画面表示とメールの両方)
2. **ファイルが正しいか** — 日本語版を買ったのに英語版が届いていないか
3. PDFが開けて、11ページあるか
4. 購入者向けメッセージが表示されるか
5. Shop → Orders に注文が記録されているか

> ⚠️ **特に2番**。日英2商品を登録すると、**アップロードするファイルを取り違えやすい**箇所です。
> 内容は同じで言語だけ違うため、間違えても登録画面では気づけません。

テスト後の注文はそのままで実害ありません。返金する場合、手数料は戻らないことが多いので、
数十円のために手間をかける必要はありません。
