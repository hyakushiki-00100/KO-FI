# チーム・役割分担

チームの構成と、それぞれの担当領域をまとめます。
1人が複数の役割を兼任しても構いません。作品ごとの担当は各作品の `README.md` に記載します。

## 役割一覧

| 役割 | 担当内容 |
| --- | --- |
| ディレクター | 全体の企画・進行管理・出品判断 |
| 作画 / デザイン | イラスト・グラフィック・レイアウト |
| シナリオ / テキスト | 文章・設定・出品説明文。記事は [`writing-persona-en.md`](writing-persona-en.md) / [`writing-persona-ja.md`](writing-persona-ja.md) の設定に従う |
| 編集 / 校正 | 誤字脱字・品質チェック・体裁調整 |
| 出品担当 | Ko-fi への登録・価格設定・公開 |
| レイアウト / 組版 | 原稿と画像からPDFを組む・表紙/サムネイル作成 |

## AIエージェント

作業の一部は Claude Code のサブエージェントに任せられます。

| エージェント | 役割 | 呼び出し方 |
| --- | --- | --- |
| [`layout`](../.claude/agents/layout.md) | 原稿+画像 → 印刷品質PDFの組版、表紙・サムネイル作成 | 「PDFにして」「組版して」等 |

> 定義ファイルは `.claude/agents/` にあります。役割を変えたいときはそのファイルを編集してください。
