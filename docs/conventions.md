# 命名・管理ルール

作品や素材が散らからないよう、最小限の共通ルールを決めます。

## 作品ディレクトリ

- 1 作品 = `works/` 直下の 1 ディレクトリ
- ディレクトリ名は分かりやすい作品名(日本語可)
- 各作品ディレクトリには必ず `README.md` を置く

## ファイルの置き場所(作品ディレクトリ内)

```
works/<作品名>/
├── README.md      … 作品の企画・進行状況
├── assets/        … 素材(元データ・下書き・参考資料)
└── output/        … 完成した成果物(出品するファイル)
```

## 命名の目安

- 制作途中のファイルには `_wip`(work in progress)を付ける 例:`cover_wip.psd`
- 完成版は `output/` に置き、バージョンは `_v2` のように付ける
- 日付を入れる場合は `YYYY-MM-DD` 形式(例:`2026-07-24`)

## Git 管理について

- テキスト・企画・説明文はコミットして履歴を残す
- 巨大なバイナリ素材(psd, 動画など)は必要に応じて管理方法を検討する
  (`.gitignore` で除外する / 別ストレージを使う など)
