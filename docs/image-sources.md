# 著作権フリー画像の探し方とライセンス注意

**販売する作品**に画像を載せるためのルールと、画像の入手先をまとめます。
「無料で見つかった」=「販売作品に使ってよい」ではありません。必ず利用条件を確認してください。

---

## ライセンス早見表(販売作品での可否)

| ライセンス | 販売作品に使える? | 条件 |
| --- | --- | --- |
| **パブリックドメイン(PD)** | ✅ 使える | 制限なし |
| **CC0** | ✅ 使える | 制限なし(クレジット不要) |
| **CC BY** | ✅ 使える | **作者クレジットの表記が必須** |
| **CC BY-SA(継承)** | ⚠️ 避ける | 作品全体を同じ条件で公開する必要が出る恐れ |
| **CC BY-ND(改変禁止)** | ⚠️ 避ける | 切り抜き・加工・レイアウト組込が問題になりうる |
| **CC ○○-NC(非営利)** | ❌ 使えない | **販売=営利なので不可** |
| ライセンス不明 | ❌ 使わない | 権利者に許諾を取れない限り使わない |

**結論:PD / CC0 / CC BY の3つだけを使う。NC と ND は避ける。**

---

## 一番確実な方法:自分で撮る

- **城・寺社などの建築物**は、日本の著作権法46条により、屋外に恒常的に設置された
  建築物として**撮影・商用利用が基本的に自由**です。
- 自分で撮った写真なら**著作権は自分のもの**。ライセンス問題が完全になくなり、
  画質・構図も自由。可能な限り現地撮影を推奨します。
- ただし**施設内の撮影ルール**(撮影禁止・フラッシュ禁止・SNS限定など)は各施設に従うこと。
  国宝の美術品・仏像は撮影禁止のことが多いので、その場合は下記のPD/CC0素材を使う。

## 著作権フリー画像の入手先

### 国宝・文化財の写真
- **Wikimedia Commons** … <https://commons.wikimedia.org/>
  各画像ページの下部でライセンス(PD / CC0 / CC BY など)を必ず確認。
- **ColBase(国立文化財機構 所蔵品統合検索)** … <https://colbase.nich.go.jp/>
  東博・京博・奈良博などの所蔵品画像。利用規約を確認して使う。
- **国立国会図書館デジタルコレクション** … <https://dl.ndl.go.jp/>
  古典籍・古い図版などにパブリックドメイン資料が多数。
- **メトロポリタン美術館 Open Access** … <https://www.metmuseum.org/art/collection>
  日本美術も所蔵。CC0 の作品が多い。
- **Google Arts & Culture** … <https://artsandculture.google.com/>
  画像ごとに条件が異なるので個別確認。

### 場所・風景の写真
- **Wikimedia Commons**(城・寺社の外観が豊富)
- **写真AC / Pixabay / Unsplash** … 無料素材だが**利用規約を必ず確認**
  (商用可・クレジット要否・再配布可否はサイトと画像で異なる)

## 使うときの記録ルール

画像を1枚使うごとに、その entry ファイルに次を必ず記録します。

- 出典URL
- 作者 / 撮影者
- ライセンス種別
- (CC BY の場合)必要なクレジット表記文

これは **クレジット表記のため**であると同時に、**後から「この画像は本当に使ってよかったか」を
検証できるようにする**ためです。出品前チェックで全画像のライセンスを最終確認します。

---

## 迷ったときの原則

- 判断に迷う画像は**使わない**(グレーは黒と同じ扱い)
- 「非営利のみ(NC)」は**販売作品では絶対に使わない**
- 一番安全で高品質なのは**自分で撮った写真**
