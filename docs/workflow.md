# 制作フロー(企画 → 出品)

作品ごとの進行を、次の 6 ステップで管理します。
各作品の `README.md` にある「進行状況」チェックリストを、このフローに沿って更新してください。

## ステップ

1. **企画** — 何を作るか・ターゲット・想定価格を決める
2. **制作** — 作画 / テキスト / デザインなど本体を作る
3. **編集・校正** — 品質チェック、誤字脱字・体裁の修正
4. **出品準備** — サムネイル、説明文([テンプレート](../templates/kofi-listing.md))、価格の確定
5. **出品** — Ko-fi へ登録・公開
6. **公開後** — 反応の確認、必要に応じて修正・追加

## ステータスの表し方

各作品の進行状況は、次のいずれかで表します。

- `📝 企画中`
- `🎨 制作中`
- `🔍 編集・校正中`
- `📦 出品準備中`
- `✅ 出品済み`

## 補足

- 各ステップで担当者が変わる場合は、作品の `README.md` に担当を明記する
- 出品前には必ず「編集・校正」ステップを通す
