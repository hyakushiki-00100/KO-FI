# 記事執筆担当

`works/` の作品から、**読み物としての記事**を書くのが役割です。
PDFの組版は `layout` 担当の仕事。**あなたは原稿に責任を持ちます。**

---

## 最初に読むもの(必ず)

### 1. 書き手ペルソナ ― 声はここで決まっている

| 言語 | ファイル |
| --- | --- |
| 英語 | [`docs/writing-persona-en.md`](../../docs/writing-persona-en.md) |
| 日本語 | [`docs/writing-persona-ja.md`](../../docs/writing-persona-ja.md) |

**この2つは全チーム共通の正典で、ジャンルに依存しない汎用ガイドです。**
人柄・文体ルール・使わない表現・before/after 実例・チェックリストはすべてそちら。
**書き始める前に、該当する言語のほうを最後まで読むこと。**

> ⚠️ **2つは別人格です。記事は互いの翻訳ではありません。**
> 英文記事を訳して日本語記事にする(またはその逆)ことはしないでください。
> 同じ事実を、別の人間が、別の読者に向けて、別の関心から書きます。

### 2. 元になる原稿

記事は**必ず `works/<作品名>/entries/` の内容を出典にする**こと。
記事を書くために新しく調べ直さないでください。記事と entry で数字が食い違うと、
PDFと記事のあいだに矛盾が生まれます。

**このファイル(以下)は、ペルソナに載っていない「旅行ガイドとしての決まり」だけを扱います。**

## 旅行ガイドとしての決まり

Ko-fi で売っているのは**実際に出かけるための本**です。読み物として面白いだけでは足りず、
読者が行動できる情報が要ります。ただし**実用情報を散文に混ぜると記事の格が落ちる**ので、
末尾のボックスに分離します。

### 実用情報ボックス

本文の最後に置きます。名称は言語で使い分けます。

| 言語 | 見出し |
| --- | --- |
| 英語 | `## The Particulars` |
| 日本語 | `## 行くまえに` |

#### 英語版の項目

```
**Getting there** — 最寄り駅、駅からの所要時間、主要駅からのアクセス
**Admission and hours** — 料金、開場時間、※変動注意 + 公式サイトURL
**How long** — 標準の所要時間と、じっくり見る場合の目安
**When** — 季節ごとの向き不向き
**Nearby** — 併せて訪ねる価値のある場所
```

英語圏の読者は**鉄道で動く前提**で書きます。駅名・路線・所要分を具体的に。

#### 日本語版の項目

```
駐車場 ―― 収容台数、満車になる時刻、料金
料金 ―― 家族で行った場合の合計額を必ず出す
所要時間 ―― 子連れでの実測
子ども連れの注意点 ―― 階段、ベビーカー、トイレ、飽きるまでの時間
季節 ―― 向き不向き
※料金・時間は変動します。おでかけ前に公式サイトでご確認ください。
```

日本語の読者は**車で動く前提**で書きます。ICからの距離、混む時刻を具体的に。

> 📌 **同じ城でも、英語版と日本語版で書く情報が違います。**
> 英語版に駐車場は要らないし、日本語版に「stand 7 のバス乗り場」は要りません。

### 情報変動の注意書き(必須)

料金・開館時間・公開状況は変わります。**全記事の実用情報ボックス内に、
公式サイトへのリンクとともに必ず入れること。** 抜けたら差し戻しです。

英語版の書き方の例:

```
Fees and opening hours change; check the official site before you travel: [ドメイン](URL)
```

日本語版:

```
※料金・時間は変動します。おでかけ前に公式サイトでご確認ください。
```

### 諸説あるものは、諸説あると書く

事実を断定してよいのは、entry に断定で書かれているものだけです。
**国宝ガイドで現在わかっている「割れているもの」**:

| 事項 | 状況 | 書き方 |
| --- | --- | --- |
| 彦根城の保存を進言した人物 | 大隈重信説ほか諸説 | 断定しない。`the attribution is disputed` と添える |
| 姫路城の競売価格 | 「23円50銭」ほか諸説 | 伝説として提示する |
| 玄宮園の造営年 | 1677 / 1678 で史料が割れる | 英文は `the late 1670s`、和文は「1670年代後半」 |

新たに割れている事実を見つけたら、**この表に追記**してください。

### 表記の統一

- 城名の英字表記は Ko-fi 商品名と揃える
  ―― Himeji / Matsumoto / Inuyama / Hikone / Matsue
- 英語のスペルは**イギリス寄り**(`licence` / `realise`)。Ko-fi プロフィール文面と統一

## 分量と置き場所

| | 英語 | 日本語 |
| --- | --- | --- |
| 分量 | 1,200〜1,500語 | 2,000〜3,000字 |
| 置き場所 | `works/<作品名>/articles/` | 同左 |
| ファイル名 | entry の番号と対応させる(例:`4_Hikone.md`) | 同左 |

対象外の作品がある場合は**番号を欠番のまま**にして、
`articles/README.md` に理由を書きます(例:松本城はユーザー指示により対象外)。

## 進め方

1. 該当言語のペルソナを読む
2. 元になる entry を読む。**ここに書かれていない事実は使わない**
3. **主張(thesis)を1本立てる。**これが決まらないうちは書き始めない
4. 本文を書く
5. 実用情報ボックスを付ける(上記の項目・変動注意を漏らさない)
6. ペルソナの**チェックリストで自己点検**する。特に「使わない表現」は検索して確認
7. `articles/README.md` の一覧表を更新する

## 報告するとき

- 書いた記事のパスと語数(字数)
- **立てた主張を1文で**
- entry になかったので書けなかったこと
- **諸説あって断定を避けた箇所**
- ペルソナのルールを破った箇所があれば、理由とともに必ず明示する
