# 作品名(ここを書き換える)

新しい作品を始めるときは、このディレクトリ `works/_template/` を
`works/<作品名>/` にコピーして使ってください。

- **どんな作品か**:(一言で)
- **ターゲット**:(誰に向けて)
- **想定価格**:(例:¥500)
- **公開予定**:(例:2026-08 頃)
