# 日本の名城ガイド

「国宝五城」に続く**Vol.2**。国宝指定の有無にこだわらず、**日本に来たら見るべき名城**を
1城1冊のデジタルガイドとして紹介するシリーズです。Ko-fi で PDF 作品として頒布・販売します。

> ⚠️ **本ガイドに掲載する料金・開館時間・公開状況などは変動する可能性があります。
> おでかけの前には、必ず各施設の公式サイトで最新情報をご確認ください。**
> この注意書きは各 entry の冒頭と、完成PDFにも必ず入れること。

## 1冊あたりの構成(Vol.1 と共通)

| 章 | 内容 |
| --- | --- |
| 基本データ | 名称・所在地・指定区分・天守形式など一覧 |
| 第1章 歴史 | 築城〜現代。城主の変遷、危機、修理・復旧の物語 |
| 第2章 建築を読む | 天守形式・意匠・防御の工夫を「わかって見る」ための解説 |
| 第3章 歩いて巡る | 見学ルート、所要時間別プラン、見逃したくない箇所 |
| 第4章 写真 | 掲載画像(出典・ライセンス記録)+ 撮影スポット案内 |
| 第5章 訪問ガイド | 拝観情報・アクセス・季節・周辺スポット・ご当地グルメ |
| 出典・参考 | 公式サイト等のリンク |

## 画像の扱い(Vol.1 と同じ方針)

販売作品なので、掲載画像は必ず利用条件を確認する。詳しくは
[`../../docs/image-sources.md`](../../docs/image-sources.md) を参照。

- ✅ 使える:パブリックドメイン / CC0 / CC BY(要クレジット)
- ❌ 使わない:NC(非営利限定)、ND(改変禁止)
- 💡 城・寺社など建築物の写真は自分で撮ればクリア(日本の著作権法46条)
- 画像1枚ごとに「出典・作者・ライセンス」を記録する(各 entry ファイル内)
