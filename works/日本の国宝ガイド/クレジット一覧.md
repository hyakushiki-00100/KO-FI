## 巻末に載せる文面(そのまま使えます)

```
── 写真クレジット ──

本書に掲載した写真は、パブリックドメイン、CC0、または
クリエイティブ・コモンズ表示ライセンス(CC BY)のもとで利用しています。

【姫路城】
・大天守 全景 … ドライブフォトグラファー, CC0, via Wikimedia Commons

(以下、使用した画像を追記)

各写真の著作権は、それぞれの撮影者・権利者に帰属します。
```

> 📌 **CC0 / パブリックドメイン**の画像はクレジット表記の義務がありませんが、
> 出典を明記しておくと読者からの信頼が高まり、後から検証もしやすくなります。
> **CC BY** の画像は表記が**必須**です(作者名・ライセンス名・出典)。

## 記録テンプレ(画像を追加するときにコピー)

```
- 対象   : (例:松本城 天守 堀越し)
- ファイル: assets/(ファイル名)
- 出典URL : https://commons.wikimedia.org/wiki/File:...
- 作者   : (撮影者名 / 自分で撮影)
- ライセンス: (Public domain / CC0 / CC BY 4.0 / 自作)
- クレジット: (CC BY の場合、掲載に必要な表記文)
- 使う場所 : (例:第2章 建築)
```
