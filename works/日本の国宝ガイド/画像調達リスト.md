# 画像調達リスト(国宝五城 Vol.1)

各城の画像を**安全なライセンスだけに絞り込んで**探すためのリンク集です。
ライセンスの考え方は [`../../docs/image-sources.md`](../../docs/image-sources.md) を参照。

> ⚠️ **この作業環境からは画像サイトに直接アクセスできません**(組織のネットワーク制限で
> Wikimedia Commons 等が 403 ブロック)。そのため下記リンクは**あなたのブラウザで開いて**
> ダウンロードしてください。落とした画像を `assets/` に置いて「ファイル名・出典・ライセンス」を
> 教えていただければ、私が各 entry に紐付けます。

## 使い方(推奨手順)

1. 下の **「① 制限なし(PD/CC0)」** リンクを開く(いちばん安全)
2. 気に入った画像を選ぶ → **ファイルページでライセンスを最終確認**
   - ✅ OK:`Public domain` / `CC0` / `CC BY`
   - ❌ 使わない:`CC BY-NC`(非営利)/ `CC BY-ND`(改変禁止)/ `GFDL`単独 / ライセンス不明
3. 「Download」から**なるべく高解像度**を保存し、`assets/` に入れる
4. ファイル名・出典URL・作者・ライセンスをメモ(entry に記録します)

> 💡 城の外観は自分で撮ればライセンス問題ゼロ&高品質。現地に行けるなら自撮りが最善。

## 古写真・絵図を使いたい場合(すべてパブリックドメイン)

明治〜昭和初期の古写真や絵図は、**国立国会図書館デジタルコレクション**に
パブリックドメイン資料が多数あります(城の歴史ページの挿絵に最適)。

- 国会図書館デジタルコレクション:<https://dl.ndl.go.jp/>
  (「姫路城」などで検索 → 公開範囲「インターネット公開(保護期間満了)」で絞る)

## 記録用テンプレ(画像を1枚使うごとにコピー)

```
- 対象   : (どの城のどの写真か)
- ファイル: assets/(ファイル名)
- 出典URL : https://commons.wikimedia.org/wiki/File:...
- 作者   : (撮影者名)
- ライセンス: (Public domain / CC0 / CC BY 4.0 など)
- クレジット: (CC BY の場合、掲載に必要な表記文)
```
