# 画像調達リスト(国宝五城)

単品1冊ごとに必要なカットを洗い出し、**安全なライセンスだけに絞り込んだ検索リンク**を
城ごとにまとめたものです。ライセンスの考え方は [`../../docs/image-sources.md`](../../docs/image-sources.md)。

> ⚠️ **この作業環境からは画像サイトに直接アクセスできません**(組織のネットワーク制限で
> Wikimedia Commons・Openverse・国会図書館デジタルコレクションがいずれも 403)。
> 下記リンクは**あなたのブラウザで開いて**ダウンロードしてください。
> 落とした画像を `assets/` に置き、ファイル名・出典・ライセンスを教えていただければ、
> 私が各 entry に紐付けて記録します。

## 共通ルール

### 使ってよいライセンス

- ✅ **PD / CC0** … 制限なし(最優先)
- ✅ **CC BY** … 使えるが**クレジット表記が必須**
- ❌ **NC(非営利)** … 販売作品なので**絶対に不可**
- ❌ **ND(改変禁止)/ GFDL単独 / ライセンス不明** … 使わない

### リンクの見方

各カットに2種類のリンクを用意しています。

- **① 制限なし** … PD/CC0 のみに絞り込み(いちばん安全。まずここから)
- **② CC BY含む** … クレジット表記すれば使えるものまで含めて探す

> 💡 **建築物の外観は自分で撮ればライセンス問題ゼロ**(日本の著作権法46条)。
> 現地に行ける城は自撮りが最善です。下の一覧は「撮影メモ」としてもそのまま使えます。

### ⚠️ 権利に注意が必要な被写体(重要)

販売作品では、次のものは**避けるか、権利者の許諾を取る**必要があります。

| 被写体 | 理由 | 対応 |
| --- | --- | --- |
| **ひこにゃん**(彦根城) | 彦根市が権利を管理するキャラクター。商用利用には許諾が必要 | **写真は掲載しない**。本文で触れるだけにする |
| ゆるキャラ・マスコット全般 | 同上 | 掲載しない |
| 近年の彫刻・キャラクター像 (例:縄手通りのカエル像) | 著作権が生きている可能性 | 避ける。写り込む場合は構図を変える |
| 博物館・資料館の**館内展示物** | 撮影禁止のことが多い。館の利用規程が優先 | 各館のルールに従う |
| 庭園・寺社の**撮影/公開ルール** | 施設ごとに商用撮影の可否が異なる | 好古園・玄宮園など、掲載前に施設へ確認 |
| 人物が判別できる写真 | 肖像権 | 顔が写り込まない構図を選ぶ |

## 古写真・絵図(すべてパブリックドメイン)

明治〜昭和初期の古写真や江戸期の絵図は、歴史章の挿絵に最適です。
**国立国会図書館デジタルコレクション** に保護期間満了の資料が多数あります。

- <https://dl.ndl.go.jp/>
  → 城名で検索 → 公開範囲を **「インターネット公開(保護期間満了)」** で絞り込む
- Commons の古写真検索:
  [姫路城](https://commons.wikimedia.org/wiki/Special:MediaSearch?type=image&haslicense=unrestricted&search=Himeji%20Castle%20old%20photograph) /
  [松本城](https://commons.wikimedia.org/wiki/Special:MediaSearch?type=image&haslicense=unrestricted&search=Matsumoto%20Castle%20Meiji) /
  [彦根城](https://commons.wikimedia.org/wiki/Special:MediaSearch?type=image&haslicense=unrestricted&search=Hikone%20Castle%20old%20photo)

> 💡 姫路城の「明治の廃城危機」「空襲を免れた話」など、歴史章は**古写真があると一気に読み物になります**。

## 記録用テンプレ(画像1枚ごとにコピーして記入)

```
- 対象   : (例:姫路城 大天守 全景)
- ファイル: assets/(ファイル名)
- 出典URL : https://commons.wikimedia.org/wiki/File:...
- 作者   : (撮影者名 / 自分で撮影)
- ライセンス: (Public domain / CC0 / CC BY 4.0 / 自作)
- クレジット: (CC BY の場合、掲載に必要な表記文)
- 使う場所 : (例:第2章 建築)
```

集まったら、この情報を私に渡してください。各 entry の画像欄に反映し、
巻末クレジット一覧も作成します。
