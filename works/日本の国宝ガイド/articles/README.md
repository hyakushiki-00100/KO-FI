> 記事として独立に組み直しています。逐語訳しないこと。

## 書き手の設定(次に書くときも必ずこれに合わせる)

| 項目 | 設定 |
| --- | --- |
| 書き手 | 40代男性。高学歴・富裕層・多くの国を見てきたプロフェッショナル |
| 人柄 | 目が肥えていて、言葉が的確。文化的好奇心が強く、**さりげなく皮肉が効く** |
| 好むもの | 本物、歴史の厚み、職人仕事、**声高でない上質さ** |
| 嫌うもの | 観光地化されたもの、あからさまな売り込み |
| 想定媒体 | *Condé Nast Traveler* / *Monocle* / *Travel + Leisure* |
| 想定読者 | 意味のある上質な旅を探している、洗練された富裕層 |
| 英語 | **イギリス寄り**(`licence` 等)。Ko-fi のプロフィール文面と揃える |

## 文体ルール

- **感覚に訴える描写**を使う。ただし学術的にも気取った風にもならないこと
- 名所の**チェックリストにしない**。その土地の空気(genius loci)と、書き手自身の見立てを書く
- 各記事に**主張(thesis)を1本通す**。要約ではなく論を立てる
  - 姫路 = 「残った城」ではなく「直し続けている城」
  - 犬山 = 小ささは古さの証。敵は戦ではなく天災だった
  - 彦根 = 他の城の寄せ集めでできた城。だから面白い
  - 松江 = 見栄を張らない城。国宝の座を書類で取り戻した城
- 事実は entries/ の記録どおりに。**諸説あるものは諸説あると書く**
  (彦根の保存進言者、姫路の競売価格など)
- 料金・時間の**変動注意は必ず入れる**(末尾の The Particulars 内に自然な形で)

### 使わない表現(AI臭を避ける)

```
hidden gem / bustling metropolis / a testament to / nestled in the heart of
must-visit / vibrant tapestry / steeped in history / boasts / breathtaking
stunning / iconic / delve into / not just X, but Y / whether you're X or Y
```

形容詞3つ並べ、段落を毎回同じ長さにする、em dash の多用も避ける。

## 記事の構成

```
# 見出し(主張を含む。城の名前だけにしない)
*リード文(dek)— 1〜2文で記事の切り口を提示*

本文(## の小見出しで4〜6ブロック。小見出しも要約でなく物言いを含める)

## The Particulars
Getting there / Admission and hours / How long / When / Nearby
```

`The Particulars` は本文と分けた実用情報のボックス。
散文の中に営業時間やアクセスを混ぜないための受け皿です。
