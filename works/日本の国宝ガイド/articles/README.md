> 記事として独立に組み直しています。逐語訳しないこと。

以下は**この作品に固有の運用メモ**だけを残しています。

### 国宝ガイド固有のルール

- 事実は `entries/` の記録どおりに。**新たに調べ直さない**
  (記事と entry で数字が食い違うと、PDFと記事で矛盾が出る)
- **諸説あるものは諸説あると書く**。この作品で該当するのは:
  - 彦根城の保存を進言した人物(大隈重信説ほか)
  - 姫路城の競売価格(「23円50銭」ほか)
  - 玄宮園の造営年(1677 / 1678 で史料が割れる → 英文では "the late 1670s")
- 城名の英字表記は Ko-fi 商品名と揃える(Himeji / Matsumoto / Inuyama / Hikone / Matsue)
- 実用情報ボックスの名称は **`The Particulars`** で統一
