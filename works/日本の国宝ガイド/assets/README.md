# assets(素材置き場)

**ダウンロード/撮影した画像は、このフォルダに入れてください。**

## 画像の保存方法(2択)

### ① GitHub にアップロードする(おすすめ・チーム共有向き)

ブラウザだけで完結します。

1. GitHub でこの `assets` フォルダを開く
2. 右上の **「Add file」→「Upload files」**
3. 画像をドラッグ&ドロップ
4. ファイル名を下の命名規則に合わせる(アップ後の鉛筆アイコンでリネーム可)
5. **「Commit changes」**

> ⚠️ ブランチが **`claude/kofi-production-team-b67gly`** になっているか確認すること。

### ② 自分のPCに貯める(一人で作業するなら十分)

PCにフォルダを作って集めるだけでもOK。このリポジトリにはテキストと記録だけを置き、
画像はPDFを作る人の手元に持つ運用です。GitHub の容量を気にせずに済みます。

**どちらでも制作は進みます。** 大切なのは**ファイル名を統一しておくこと**だけ。
名前さえ揃っていれば、PDF化のときに各 entry の記述とそのまま突き合わせられます。

## 場所

```
KO-FI/
└── works/
    └── 日本の国宝ガイド/
        ├── assets/     ← ここ(画像を入れる)
        ├── entries/    … 各城の本文
        └── output/     … 完成したPDF
```

## ファイル名の付け方

`城名_内容.拡張子` の形にすると、あとで探しやすく、entry への紐付けも簡単です。

```
姫路城_大天守_全景.jpg
姫路城_菱の門.jpg
姫路城_好古園.jpg
松本城_天守_堀越し.jpg
犬山城_木曽川対岸.jpg
彦根城_玄宮園から天守.jpg
松江城_堀川めぐり.jpg
```

- 制作途中のものには `_wip` を付ける(例:`姫路城_表紙_wip.psd`)
- 差し替えたら `_v2` のようにバージョンを付ける

## 画像を入れたら、必ず記録を残す

**どこから取ってきたか・どのライセンスかが分からない画像は使えません。**
1枚ごとに、次の情報をメモして渡してください(entry と巻末クレジットに反映します)。

```
- 対象   : (例:姫路城 大天守 全景)
- ファイル: 姫路城_大天守_全景.jpg
- 出典URL : https://commons.wikimedia.org/wiki/File:...
- 作者   : (撮影者名 / 自分で撮影)
- ライセンス: (Public domain / CC0 / CC BY 4.0 / 自作)
- クレジット: (CC BY の場合、掲載に必要な表記文)
- 使う場所 : (例:第2章 建築)
```

## 使えるライセンス(販売作品なので重要)

- ✅ パブリックドメイン / CC0 / CC BY(要クレジット)
- ❌ NC(非営利限定)/ ND(改変禁止)/ ライセンス不明
- 💡 **自分で撮った写真がいちばん安全**

詳しくは [`../../../docs/image-sources.md`](../../../docs/image-sources.md)、
どのカットが必要かは [`../画像調達リスト.md`](../画像調達リスト.md) を参照。
