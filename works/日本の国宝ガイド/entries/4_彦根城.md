# 彦根城(ひこねじょう)

> ⚠️ **掲載の料金・開館時間・公開状況は変動する可能性があります。おでかけ前に必ず
> [国宝 彦根城 公式サイト](https://hikonecastle.com/)でご確認ください。**

いくつもの城から部材を集めて建てられた、寄せ集めの天守。
それでいて破風を重ねた姿は華やかで、庭園から望む眺めは絶景――
「継ぎ足された城」が国宝になった理由を歩いて確かめる一冊。

## 第1章 歴史 ── 七つの城から集められた天守

### 「井伊の赤備え」が築いた城

関ヶ原の戦いで武功を挙げた**井伊直政**は、石田三成の旧領・佐和山を与えられ入城しました。
真っ赤な甲冑で戦場を駆けた「井伊の赤備え」で知られる直政ですが、
関ヶ原での戦傷がもとで1602年(慶長7年)に世を去ります。

新たな城地を彦根山(金亀山)に定め、築城を引き継いだのは長男の**井伊直継**。
1603年(慶長8年)に工事が始まり、1607年(慶長12年)頃に完成したと伝わります。

### 城じゅうが「移築のパッチワーク」

彦根城の建物には、**他の城から移築された**という伝承が数多く残ります。

- **天守**:大津城(京極高次の城)から移築という伝承
- **天秤櫓**:長浜城からの移築と伝わる
- **佐和口多聞櫓**(非現存):佐和山城から
- **西の丸三重櫓**:小谷城から

とりわけ**太鼓門櫓**は、解体修理時の部材調査で「どこかの城の城門だった」ことが
判明したものの、**移築元の城名は今も特定されていません**。徳川家康の天下普請のもと、
周辺の廃城となった城々から使える部材を惜しみなく集めて仕上げた城――
それが彦根城の正体です。統一感のなさこそ、この城の来歴を物語っています。

### 大坂の陣と直孝

1614〜1615年(慶長19〜20年)の大坂冬の陣・夏の陣で、直継の弟・**井伊直孝**が
武功を挙げます。これにより家督は直孝へ譲られ、以後、井伊家は彦根藩主として
明治まで代々この城を治めました。

### 危機 ── 解体の足場が組まれた城

明治維新後、廃城令により多くの城が姿を消すなか、彦根城もその危機に直面します。
1878年(明治11年)、**明治天皇の北陸巡幸**の際、彦根に立ち寄ることになりました。
このとき天守は**すでに解体の足場が組まれる**ところまで話が進んでいたと伝わります。

巡幸に同行していた大隈重信(諸説では天皇の従兄弟にあたる人物ともいわれる)が
天守の保存を進言し、明治天皇の裁断によって解体は取りやめられました。

> 📌 **コラム**:誰が保存を進言したかについては、大隈重信説のほか複数の異説があり、
> 詳しい経緯は今も完全には確定していません。ただ、**あと一歩で失われていた**
> という緊迫した状況だけは、複数の記録が一致して伝えています。

姫路城が競売の安値落札という逸話で知られるように、彦根城もまた
「保存が決まったのは偶然と一人の進言だった」という、薄氷の上に残った城なのです。

### 玄宮園の造営

天守だけでなく、庭園も彦根城の見どころです。1677年(延宝5年)頃、4代藩主
**井伊直興(直該)**が、琵琶湖の景観を写した近江八景にならい、
池を中心とする回遊式庭園「**玄宮園**」を造営しました。
1813年(文化10年)には11代藩主・直中の隠居所として再整備され、現在の姿になっています。

## 第2章 建築を読む ── 小さくても、これほど華やかに

### 多彩な破風が生む「密度の高い」外観

彦根城の天守は三重三階、五城のなかでも小ぶりな部類に入ります。
しかしその外観は、**切妻・入母屋・唐破風**を惜しみなく組み合わせた、
変化に富む意匠でまとめられています。1階と2階の窓には**華頭窓(かとうまど)**も配され、
小さな天守を「密度」で見せる工夫が随所に見られます。姫路城の均整の取れた美しさとは
対照的な、**装飾性で魅せる天守**といえるでしょう。

### 天秤櫓 ── 橋を落とせば本丸は孤立する

本丸の入り口を守るのが**天秤櫓**。堀切(空堀)の上に架かる橋を渡った先に立つ、
左右対称の2重2階櫓を長い多聞櫓でつないだ構造で、
その形が天秤ばかりのように見えることから名づけられました。
橋を落とせば本丸は堀切で完全に分断され、侵入者を足止めできる仕組みです。
**美しい左右対称の意匠**と**実戦的な防御機能**を兼ね備えた、彦根城随一の見どころです。

### 「継ぎ足しの城」だからこその個性

第1章で見たとおり、彦根城の建物は由来がそれぞれ異なります。統一された設計思想で
一から築かれた姫路城とは対照的に、彦根城は**各地の城から集めた部材を組み合わせた
「集合体」**。天守・天秤櫓・太鼓門櫓が少しずつ違う表情を見せるのは、
その来歴ゆえです。**バラバラの部材が一つの城として機能している**こと自体が、
築城技術の高さを物語っています。

### 江戸時代の城の全体像が残る稀有な例

多くの城は天守や一部の櫓だけが残り、周囲の建物や堀は失われています。
彦根城は天守・附櫓・多聞櫓に加え、**天秤櫓・太鼓門櫓・西の丸三重櫓**などの
重要文化財建築が現存し、**内堀・中堀もほぼ完存**。江戸時代の城が
「天守だけの建物」ではなく、**堀・櫓・庭園を含む一つの町だった**ことを
今に伝える、数少ない例のひとつです。

## 第3章 歩いて巡る ── 見学ルートガイド

### 標準ルート

```
表門橋 → 天秤櫓(堀切と橋) → 太鼓門櫓 → 本丸・天守(地下〜3階)→
西の丸三重櫓 → 黒門 → 玄宮園(天守を望む庭園)
```

### 所要時間の目安

| プラン | 時間 | 内容 |
| --- | --- | --- |
| 天守のみ | 約60分 | 表門橋〜天守〜黒門 |
| 標準 | 約90分〜2時間 | 天守+玄宮園 |
| じっくり | 約2〜3時間 | 彦根城博物館まで含めて巡る |

> 💡 天守内部は**急な階段**が続きます。歩きやすい靴と、両手が空く荷物がおすすめです。
> ゆるキャラ「ひこにゃん」は城内に1日3回登場(時間・場所は公式サイトで確認)。

### 見逃したくないポイント

- **天秤櫓**:堀切に架かる橋越しに見上げる、左右対称の美しい構え
- **天守の破風**:切妻・入母屋・唐破風が重なる、密度の高い意匠に注目
- **玄宮園から望む天守**:池越しに天守を望む、彦根城随一の絶景
- **太鼓門櫓**:出自不明という「移築の謎」を意識して眺めると面白い

- **最寄り駅**:JR「彦根駅」
- **駅からの経路**:駅西口から徒歩約15分
- **車の場合**:周辺に有料駐車場あり
- **所要時間の目安**:米原駅からJRで彦根駅まで約5分

### 季節ごとの楽しみ

| 季節 | 見どころ |
| --- | --- |
| 春 | 桜と天守。玄宮園の新緑も美しい |
| 夏 | 濠端の緑と天守のコントラスト |
| 秋 | 玄宮園の紅葉。池に映る天守が見もの |
| 冬 | 空気が澄み、天守の破風の意匠がくっきり見える |

### あわせて訪ねたい

- **玄宮園(げんきゅうえん)**:天守を借景にした大名庭園。池越しに天守を望む眺めは彦根城随一
- **夢京橋キャッスルロード**:城の京橋からすぐ。白壁と黒格子で統一された江戸城下町風の街並み
- **四番町スクエア**:大正洋風建築が並ぶレトロな一角
- **彦根城博物館**:井伊家伝来の甲冑・美術品を展示。「井伊の赤備え」の実物にも出会える

### 彦根の味

- **近江牛**:近江(滋賀県)を代表するブランド牛。彦根でも味わえる
- **赤こんにゃく**:鉄分で赤く染めた滋賀名物のこんにゃく。独特の臭みがなく食感が良い
- **ひこね丼**:近江牛の牛すじ煮込みと赤こんにゃくを合わせた、彦根のご当地丼
