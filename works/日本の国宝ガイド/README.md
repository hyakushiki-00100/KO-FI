# 日本の国宝ガイド

日本の「国宝」を、**写真 + 解説 + 所蔵場所 + アクセス方法**で紹介するデジタルガイド。
Ko-fi で PDF 作品として頒布・販売することを目指します。

## 収録内容(1件あたり)

各国宝について、次の5項目をセットで紹介します。

1. 国宝の名称・概要
2. 国宝の写真(**著作権フリー**のもの)
3. 展示・所蔵場所(博物館・寺・神社)の紹介
4. 展示・所蔵場所の写真(**著作権フリー**のもの)
5. 場所までのアクセス方法

> 各国宝の情報は `entries/` に1ファイルずつ作成します。雛形は [`entries/_template.md`](entries/_template.md)。

## 概要

- **どんな作品か**:日本の国宝を写真つきで紹介し、実際に見に行けるガイド
- **ターゲット**:歴史・寺社・城・美術が好きな人、旅行の計画に使いたい人
- **想定価格**:(例:¥500〜)
- **公開予定**:(未定)

## 画像の扱い(重要)

販売作品なので、掲載画像は必ず利用条件を確認します。詳しくは
[`../../docs/image-sources.md`](../../docs/image-sources.md) を参照。

- ✅ 使える:パブリックドメイン / CC0 / CC BY(要クレジット)
- ❌ 使わない:NC(非営利限定)、ND(改変禁止)
- 💡 城・寺社など**建築物の写真は自分で撮ればクリア**(日本の著作権法46条)
- 画像1枚ごとに「出典・作者・ライセンス」を記録する(各 entry ファイル内)
