# 日本の名刹ガイド

「国宝五城」「日本の名城ガイド」に続く**Vol.3**。城ではなく**寺社(名刹)**を1寺1冊のデジタルガイド
として紹介する新シリーズ。第1作は**善光寺(長野県長野市)**。Ko-fi で PDF 作品として頒布・販売します。

> ⚠️ **本ガイドに掲載する料金・開館時間・公開状況などは変動する可能性があります。
> おでかけの前には、必ず各施設の公式サイトで最新情報をご確認ください。**
> この注意書きは各 entry の冒頭と、完成PDFにも必ず入れること。

## 1冊あたりの構成(Vol.1・Vol.2 と共通の章立てを踏襲。寺社向けに章名を調整)

| 章 | 内容 |
| --- | --- |
| 基本データ | 名称・所在地・宗派・創建年など一覧 |
| 第1章 歴史 | 創建〜現代。信仰の広がり、危機、再建の物語 |
| 第2章 建築・見どころを読む | 本堂・山門などの意匠、信仰上の意味を「わかって見る」ための解説 |
| 第3章 歩いて巡る | 参拝ルート、所要時間別プラン、見逃したくない箇所 |
| 第4章 写真 | 掲載画像(出典・ライセンス記録)+ 撮影スポット案内 |
| 第5章 訪問ガイド | 参拝情報・アクセス・季節・周辺スポット・ご当地グルメ |
| 出典・参考 | 公式サイト等のリンク |

> 各寺社の情報は `entries/` に1ファイルずつ作成する。雛形は [`entries/_template.md`](entries/_template.md)
> (Vol.2の雛形をそのまま流用。寺社向けの見出しは執筆時に調整する)。
> 使用画像の記録・巻末クレジットは [`クレジット一覧.md`](クレジット一覧.md)。
