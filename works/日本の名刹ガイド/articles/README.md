# 英文記事(magazine-style articles)

PDFガイドブック(`entries/`)とは**別系統の成果物**。
英語圏の読者向けに、高級旅行誌のトーンで書き下ろした**読み物としての記事**です。
Vol.1「日本の国宝ガイド」の [`articles/`](../../日本の国宝ガイド/articles/README.md) と同じ運用に揃えています。

> ⚠️ **entries/ の翻訳ではありません。** 同じ史実を使いますが、構成・語り口・切り口は
> 記事として独立に組み直しています。逐語訳しないこと。

### 名刹ガイド固有のルール

- 事実は `entries/` の記録どおりに。**新たに調べ直さない**
  (記事と entry で数字が食い違うと、PDFと記事で矛盾が出る)
- 寺社名の英字表記は Ko-fi 商品名・サムネイル・PDFファイル名と揃える(**Zenkoji**)
- 実用情報ボックスの名称は **`The Particulars`** で統一。
  料金・時間の**変動注意+公式サイトリンク**を必ず入れる
  (善光寺は **2026年4月1日の料金改定**に触れ、旧料金¥1,200が古い情報に残っている点まで書いた)
- **諸説あるものは諸説あると書く**。この作品で該当するのは:

| 事項 | 状況 | 記事での書き方 |
| --- | --- | --- |
| 創建の経緯(552年伝来・本田善光・644年伽藍) | すべて『善光寺縁起』の伝承。entry も「伝わる」表記 | `transmitted account rather than documented fact` と明示 |
| 本尊が日本最古の仏像 | 伝承 | 同上。断定しない |
| 火災の回数「十数度」 | 出典で数え方が揺れる | `something over a dozen fires (the count varies by source)` |
| 仲見世通りの長さ・店舗数 | 200m/400m、50軒/60店舗で割れる | entry の採用値(約200m・50〜60軒)に従い、幅を持たせる |
| 輪蔵の重量 | 3.8t/約5t で割れる | **記載しない**(entry も省略) |
| 次回御開帳(2027年4月4日〜6月19日) | 「予定」 | `scheduled for` と書く |

### entry にあって記事に入れなかったもの

- 撞木造の名称の由来以外の建築細部、木鼻の彫刻
- 濡れ仏の重要美術品指定、六地蔵の六道の内訳
- 山門の額の筆者(輪王寺宮公澄法親王)
- 大勧進の住職を「貫主」と呼ぶこと
- 門前の味のうち、みそソフト・七味ソフト・信州そばの老舗
